딸깍

저장한 정보를, 딸깍 한 번에.

다른 앱에서 발견한 링크·텍스트·이미지·PDF를 공유 메뉴로 보내 두면, 날짜·금액·쿠폰 코드 같은 정보를 기기 안에서 후보로 찾아 주고, 사용자가 확인한 날짜로만 알림을 만들어 주는 개인용 정보함이에요.

기기 안에만 저장

  • 로그인·회원가입·서버가 없어요.
  • 광고·분석·추적 도구를 쓰지 않아요.
  • 공유된 링크의 웹페이지를 자동으로 불러오지 않아요.

자주 묻는 질문

공유 메뉴에 딸깍이 안 보여요.
처음에는 공유 목록 끝의 ‘더보기’ 안에 있을 수 있어요. 한 번 쓰고 나면 앞쪽에 보이는 경우가 많아요.

이미지 속 글자도 읽나요?
아직은 지원하지 않아요. 이미지는 그대로 저장되고, 제목과 날짜는 직접 입력할 수 있어요.

알림이 늦게 와요.
방해 금지·절전 모드에 따라 알림이 늦거나 오지 않을 수 있어요. 앱의 알림 탭에서 다가오는 기한을 항상 확인할 수 있어요.

휴대폰을 바꾸면 데이터는요?
설정 > 내보내기로 JSON 파일을 만든 뒤 새 기기에서 가져오기 하세요. 이미지·PDF 첨부는 내보내기에 포함되지 않아요.
