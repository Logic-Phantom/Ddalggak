# 위협 모델

| 위협 | 대응 (구현됨) | 남은 위험 |
|---|---|---|
| 악성 공유 payload (스크립트/HTML) | 텍스트는 RN `Text`로만 렌더링, WebView 없음 | - |
| 위장 파일 (확장자만 jpg) | 복사 후 헤더 스니핑, 계열 불일치 거부, 허용 목록(jpeg/png/heic/heif/webp/pdf) | HEIC 하위 브랜드 일부 미인식 가능 |
| 경로 탈출 파일명 (`../`) | `sanitizeFileName` + 생성 id 접두사, 항목별 폴더 | - |
| 거대 파일/대량 공유 | 25MB, 항목 10개, 텍스트 2만 자 제한. OCR은 2의 거듭제곱 샘플링으로 긴 변 3072px 이하로 디코딩, PDF는 앞 3쪽만, 메모리 부족·60초 초과는 실패로 처리(원본은 저장) | 실기기 메모리 측정 없음 |
| 압축 파일 | 지원 안 함(자동 해제 없음) | - |
| SQL 주입 (OCR/공유 텍스트) | 모든 쿼리 파라미터 바인딩, LIKE `ESCAPE` | - |
| 원격 URL을 통한 추적/SSRF성 요청 | 앱은 URL을 조회하지 않음. 열기는 사용자 확인 후 OS 브라우저, http/https만, 사설 IP 경고 | 브라우저 이후는 범위 밖 |
| 잠금화면 알림으로 민감정보 노출 | 알림 본문에 코드/금액/원문 없음, 제목 자동 제안 시 코드·전화번호 마스킹 | 사용자가 직접 입력한 제목은 그대로 표시됨 |
| 목록 화면 어깨너머 노출 | 쿠폰·주문·예약·티켓 번호·전화는 상세에서도 기본 가림, 눈 아이콘으로 표시 | 앱 전환 화면(스냅샷) 가림 미구현 |
| 기기 분실/루팅 | OS 샌드박스 의존 | **DB·파일 암호화 없음**, 앱 잠금 없음 → Phase 5에서 SQLCipher/OS 파일 보호 등급 평가 |
| OTP/비밀번호 수집 | 인증번호·OTP·비밀번호·CVC 줄은 필드로 추출하지 않음 | OCR 원문에는 남을 수 있음(원문 저장 끄기로 대응) |
| 로그 유출 | 범주만 기록 | - |
| 가져오기 파일 변조 | 스키마·버전(v1/v2)·id 중복·날짜 검증, 48MB/5000개 제한. v2는 항목·첨부 id를 `[A-Za-z0-9_-]`로 제한(폴더 이름이 되므로), 파일 이름은 백업 값을 쓰지 않고 생성 id + 정리된 이름, base64 형식·크기·SHA-256·헤더 MIME 검증 후에만 DB 반영(단일 트랜잭션), 실패 시 쓴 파일 삭제 | 압축 해제 없음(zip 미사용) |
| 백업 파일 유출 | 내보내기 전 "암호화되지 않음·민감 정보 포함" 경고, 목적지는 사용자가 공유 시트에서 선택 | **백업 암호화 없음** — 후속 과제(비밀번호 기반 암호화 검토) |
| OCR 라이브러리의 진단 전송 | 설정에서 OCR 끄기, 개인정보 문서에 고지 | ML Kit가 보내는 진단 정보를 앱이 끌 공식 방법 없음(PRIVACY.md) |
| 임시 URI 만료로 인한 데이터 손실 | 즉시 앱 폴더로 복사, 실패 시 사유 안내 | 실기기 미검증 |
