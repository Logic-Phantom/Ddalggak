## 자세한 설명 (4000자 이내 · 현재 1236자)

```
카톡으로 받은 예약 문자, 브라우저에서 본 행사 링크, 갤러리의 쿠폰 사진.
나중에 쓰려고 저장해 두지만, 정작 필요할 때는 어디 있는지 모르거나 기한을 놓치곤 하죠.

KeepOn(킵온)은 다른 앱의 공유 메뉴에서 ‘KeepOn’을 고르기만 하면 정보를 한곳에 모아 주는 개인용 정보함이에요.

■ 공유하면 모여요
• 카카오톡·브라우저·갤러리·파일 앱의 공유 메뉴에서 링크, 텍스트, 이미지, PDF를 보낼 수 있어요.
• 앱 안에서 직접 붙여 넣거나 사진·파일을 골라 추가할 수도 있어요.
• 링크는 주소만 저장하고, 앱이 웹페이지를 자동으로 불러오지 않아요.

■ 날짜·금액·코드를 찾아 드려요
• 텍스트 속 날짜(“11월 2일 저녁 7시”, “D-3”, “2026.12.31까지”), 금액, 쿠폰·주문·예약 번호, 전화번호, 주소를 기기 안의 규칙으로 찾아요.
• 찾은 값은 ‘후보’예요. 근거 문장과 함께 보여 드리고, 직접 확인하거나 고칠 수 있어요.
• 쿠폰·예약 번호는 기본으로 가려 두어 화면을 보여 줄 때도 안심이에요.

■ 확인한 날짜로만 알림
• 사용자가 ‘이 값이 맞아요’를 누른 날짜로만 알림을 만들어요. 틀린 날짜로 울리는 일이 없어요.
• 당일·하루 전·3일 전·일주일 전 중에서 고를 수 있어요.
• 알림 권한을 허용하지 않아도 알림 탭에서 다가오는 기한을 모아 볼 수 있어요.

■ 보기 쉽게 정리
• 장소, 쇼핑, 영수증, 쿠폰, 예약, 행사, 티켓, 보증서, 문서, 링크로 자동 분류 후보를 보여 줘요.
• 홈에서 다가오는 기한과 최근 저장한 정보를 한눈에.
• 검색, 태그, 고정, 완료·보관으로 정리해요.

■ 기기 안에만 저장
• 로그인과 회원가입이 없어요.
• 모든 정보는 이 기기 안에만 저장되고, 개발자 서버로 보내지 않아요.
• 광고, 분석, 추적 도구를 쓰지 않아요.
• 사진첩 전체 접근 권한 없이, 직접 고른 사진만 읽어요.
• 설정에서 전체 데이터를 JSON으로 내보내거나 한 번에 지울 수 있어요.

■ 알아 두세요
• 이미지 속 글자 인식(OCR)은 아직 지원하지 않아요. 이미지는 그대로 저장되고, 제목과 날짜는 직접 입력할 수 있어요.
• 공유 메뉴에서 ‘KeepOn’이 처음에는 ‘더보기’ 안에 있을 수 있어요.
• 보내는 앱에 따라 링크나 텍스트만 전달될 수 있어요.
• 기기 설정(방해 금지, 절전 모드)에 따라 알림이 늦거나 오지 않을 수 있어요.
• 앱을 삭제하면 기기 안의 데이터도 함께 지워져요. 필요하면 먼저 내보내기를 해 주세요.
```

### 스크린샷 주의
- **Galaxy Z Flip5 화면(1080×2640)은 비율이 2.44:1이라 그대로 올리면 거절된다.** 1080×2160(2:1) 이하로 위·아래(상태바·내비게이션 바)를 잘라 내거나, 에뮬레이터(Pixel 1080×1920/2400 중 2:1 이하 기기)로 찍는다.
- 가상 데이터만 사용. 실제 이름·전화번호·주소·쿠폰 코드·대화가 보이면 안 된다(상태바 알림 아이콘도 확인).
- 촬영 명령(USB 연결 시): `adb exec-out screencap -p > shot-01.png`

### 촬영 목록 (권장 6장, 위 캡션은 스크린샷 위에 얹을 문구 후보)
1. 홈 — 다가오는 기한 카드 2~3개 + 최근 저장 — "필요한 정보를 한곳에"
2. 다른 앱(브라우저 등) 공유 시트에서 KeepOn 선택 → 공유받은 정보 화면 — "공유 메뉴에서 KeepOn"
3. 정보 확인하기 — 날짜 후보·근거·확인 버튼 — "날짜·금액·코드는 후보로 찾아 드려요"
4. 상세보기 — 예약번호 가림 상태 + 알림 만들기 시트 — "확인한 날짜로만 알림"
5. 알림 탭 — 예약된 알림·다가오는 날짜 — "기한을 놓치지 않게"
6. 마이 또는 개인정보 처리방침 — "로그인 없이 기기 안에만 저장"
