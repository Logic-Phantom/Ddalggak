# 비공개 테스트 진행 가이드

> 2023-11-13 이후 만든 **개인** 개발자 계정은 프로덕션 출시 전에 비공개 테스트를 거쳐야 한다.
> 2026-10-26 기준으로 알려진 요건: **테스터 12명 이상이 14일 연속으로 참여(옵트인 유지)**. Play Console 대시보드의 "프로덕션 액세스 권한 신청" 카드에 표시되는 현재 요건을 기준으로 한다.

## 1. 일정 (예시)

| 날짜 | 할 일 |
|---|---|
| D-0 | production 프로필 AAB 빌드 → 내부 테스트에 업로드 → 본인 기기 설치 확인 (`RELEASE_CHECKLIST.md` 4장) |
| D-0 | 비공개 테스트 트랙 생성, 테스터 목록(이메일) 등록, AAB 승격, 검토 제출 |
| D-1~2 | 검토 통과 → 테스터에게 참여 링크 전송 (아래 3장 문구) |
| D-2~D-16 | 14일 이상 유지. 중간에 수정 빌드를 올려도 기간은 이어짐. 피드백 수집 |
| D-16+ | 대시보드에서 프로덕션 액세스 신청 → 설문(테스트 방법·피드백·변경 사항) 작성 |

테스터가 중간에 옵트아웃하거나 앱을 지우면 인원 수에서 빠질 수 있으니 **15명 이상** 모으는 것을 권장한다.

## 2. Play Console 설정

1. 테스트 및 출시 > 테스트 > 비공개 테스트 > 트랙 만들기(또는 기본 "Closed testing - Alpha")
2. 국가/지역: 대한민국
3. 테스터: "이메일 목록" 생성 → 테스터의 **Google Play 계정 이메일**(Gmail) 입력. Google 그룹을 써도 된다.
4. 피드백 URL 또는 이메일: `dlacoaud96@gmail.com`
5. 새 버전 만들기 → 내부 테스트의 AAB를 승격하거나 새로 업로드 → 출시 노트(`PLAY_STORE_LISTING.md`) → 검토 후 출시
6. 검토가 끝나면 "테스터 > 웹에서 참여" 링크를 복사해 테스터에게 보낸다.

```

카톡·브라우저·갤러리에서 공유 버튼으로 보낸 링크·쿠폰·예약 정보를 모아 두고,
확인한 날짜로 알림을 받는 앱이에요. 로그인 없이 기기 안에만 저장돼요.

• 기간: 14일 (설치해 두고 가끔 써 보시면 돼요)
• 필요한 것: 안드로이드 폰, Gmail 주소
• 참여 방법: Gmail 주소를 알려 주시면 테스트 링크를 보내 드려요

Google Play 정책상 14일 동안 앱을 지우지 말고 테스트 참여 상태를 유지해 주세요.
```

## 4. 프로덕션 액세스 신청서 메모

신청 시 테스트 내용을 묻는 설문이 나온다. 아래를 테스트 중에 기록해 두면 답하기 쉽다.
- 모집 방법(지인·커뮤니티), 실제 참여 인원, 기간
- 받은 피드백과 그에 따라 고친 것(버전·날짜)
- 프로덕션 준비가 됐다고 판단한 근거(크래시 없음, 핵심 흐름 확인 등)
