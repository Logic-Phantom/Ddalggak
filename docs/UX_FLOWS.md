# UX 흐름

## 1. 첫 실행
인박스 상단 카드: 앱이 하는 일, 기기 안 저장, 앱이 스스로 대화/사진첩을 읽지 않음 → "알겠어요"/"개인정보 안내". 가입·권한 팝업 없음.

## 2. 다른 앱에서 공유
공유 메뉴 → KeepOn → `/capture?source=share` → "받은 내용" 목록(형식·도메인, 빼기 가능), 거부된 항목은 사유 안내 → "정리하기".
공유 내용이 없으면 "공유된 내용을 찾지 못했어요" + 붙여넣기/선택 대안.

## 3. 직접 추가
추가하기 → 텍스트/링크 입력 · 붙여넣기 · 사진 선택 · 파일 선택 → 정리하기.

## 4. 검토
OCR 상태 안내(현재: 미지원 안내), 같은 링크 중복 안내 → 제목, 분류(후보 + 근거 키워드), 찾은 정보(값·의미·신뢰도·근거 보기·이 값이 맞아요·수정·삭제), 직접 추가(날짜/금액/상호/주소/쿠폰 코드), 메모, 태그 → 하단 "확인이 필요한 값 N개 — 확인 전 값으로는 알림을 만들지 않아요" → 저장 / 버리기.

## 5. 상세 → 행동
링크 열기(확인 대화상자), 정보(확인 토글), 알림 만들기(확인된 날짜 또는 직접 입력, 당일/하루 전/3일 전/일주일 전), 첨부(다른 앱으로 열기·삭제), 원문 펼치기, 수정, 완료/보관/되돌리기, 삭제(확인).

## 6. 찾기
- 인박스: 최근 저장 / 검토 필요 / 7일 안 기한, 분류 칩 → 분류별 목록.
- 검색 탭: 여러 단어 AND, 보관·완료 포함 토글.
- 기한 탭: 예약된 알림, 확인한 날짜(60일), 최근 지난 날짜(7일). 알림 권한이 없으면 안내 + 기기 설정 열기.

## 7. 설정
첨부 보관, OCR 원문 저장(끄면서 기존 원문 삭제 선택), 기본 알림 시각, 보관함·완료, 내보내기(경고), 가져오기, 모든 데이터 삭제(경고), 개인정보 안내, OCR 지원 상태.

## 오류/빈 상태 구현 현황
| 상황 | 구현 |
|---|---|
| 저장된 항목 없음 | 인박스 EmptyState |
| 공유 payload 없음/미지원 형식 | 캡처 화면 안내 |
| 파일 읽기 실패/임시 URI 만료 | `file-access-lost` 안내, 나머지 입력은 계속 |
| OCR 미지원/실패/PDF | 검토 화면 안내 + 수동 입력 |
| 추출 결과 없음/낮은 신뢰도 | "찾은 값이 없어요", 확인 필요 배지 |
| 잘못된/과거 날짜 | 입력 형식 오류, 알림 생성 거부 사유 |
| 알림 권한 거부/예약 실패 | 앱 내 저장 + 기한 탭 안내 |
| DB 열기 실패 | ErrorState + 다시 시도 |
| 가져오기 실패 | 검증 오류 최대 3개 표시 |
| 첨부 누락(DB-파일 불일치) | 시작 시 reconcile로 정리 |
| 저장 공간 부족 | `storage-failed` 메시지 정의(파일 복사 실패 시 `file-access-lost`로 표시됨 — 세분화 필요) |
| OCR 진행/취소/재시도 | OCR 미연결로 미구현 |
