### 2026-10-25 실기기 OCR 시험 (같은 빌드, Galaxy Z Flip5)
입력: 직접 만든 **가상 쿠폰 이미지 1장**(1080×1500 PNG, Pretendard 글꼴, 정면·선명, "테스트용 가상 이미지" 표기). 추가 화면 → 파일 → 이미지 선택 → 저장하기.

| 기대값 | 결과 |
|---|---|
| OCR 실행 | ✅ "이미지에서 글자를 읽었어요" 표시, 저장하기 → 확인 화면까지 약 7초(uiautomator 조회 시간 포함, 엔진 단독 시간은 미측정) |
| 제목 | ✅ "딸깍카페 모바일 교환권" |
| 분류 | ✅ 쿠폰 |
| 만료일 2026.12.31 | ✅ 만료일 2026.12.31(목), "이미지에서 읽음", 확인 권장(자동 확정 안 됨) |
| 결제 금액 4,500원 | ✅ 4,500원 |
| 쿠폰번호 8812-4473-9905 | ✅ 정확히 추출, 가림 버튼 있음 |
| 인증번호 482913 제외 | ✅ 후보에 없음 |
| 사용처(상호) | 추출 안 됨 — "사용처:"는 상호 라벨 규칙 밖(기존 규칙대로) |
| 크래시·오류 로그 | 없음 |

한계: 선명한 합성 이미지 1장뿐이라 **정확도 측정이 아님**. 사진 촬영본·기울기·흐림·작은 글자·PDF·임시 저장 후 "이미지 글자 읽기"는 미시험.
정리: 시험 도중 휴대폰 앞 화면이 다른 앱(CutPick)으로 바뀌어 조작을 중단함 → 딸깍 안의 확인 화면 항목(draft)은 "버리기" 확정을 못 했을 수 있음(draft는 1일 뒤 자동 삭제). 휴대폰 Download의 테스트 이미지는 삭제함.
