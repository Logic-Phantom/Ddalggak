# 개인정보 처리 설계 (PRIVACY)

> 앱의 실제 동작을 설명하는 개발 문서다. 법률 자문이 아니며, 정식 출시 전 별도의 개인정보 처리방침과 전문가 검토가 필요하다.

## 입력 경로
- OS 공유 메뉴로 사용자가 보낸 텍스트/URL/이미지/PDF
- 앱 안의 사진 선택기·문서 선택기(사용자가 고른 파일만)
- 붙여넣기(버튼을 눌렀을 때만 클립보드 읽음)
- 앱은 카카오톡·SMS·이메일·사진첩을 스스로 읽거나 백그라운드에서 스캔하지 않음. 사진 전체 접근 권한(READ_MEDIA_*)은 Android 매니페스트에서 차단.

## 저장
| 데이터 | 위치 | 사용자 통제 |
|---|---|---|
| 제목·메모·태그·추출값 | SQLite(앱 전용) | 항목 수정·삭제 |
| 공유 원문(display_text) | SQLite | 항목 삭제 |
| OCR 원문 | SQLite | 설정에서 저장 끄기 + 기존 원문 일괄 삭제 |
| 이미지/PDF 사본 | 앱 전용 폴더 | 설정에서 보관 끄기, 첨부별 삭제 |
| 알림 | OS 로컬 알림 + DB | 알림별 삭제, 항목 보관/완료 시 자동 취소 |

DB와 파일은 **암호화되어 있지 않다**. iOS/Android 앱 샌드박스가 다른 앱의 접근을 막지만, 기기 백업·루팅/탈옥 환경에서는 보호 수준이 달라진다(THREAT_MODEL.md).

## 기기 밖 전송
- 앱 코드: **없음.** 링크 미리보기 자동 조회 없음, 원격 OCR/LLM 없음, 분석·광고·크래시 리포트 SDK 없음.
- 사용자가 "열기"를 누르면 링크를 OS 브라우저로 넘김(그 이후는 브라우저/사이트의 정책).
- 사용자가 "내보내기"를 누르면 백업 JSON 파일을 OS 공유 시트로 넘김(목적지는 사용자가 선택). 민감 정보 포함·암호화되지 않음 경고를 먼저 표시.

## 이미지 글자 인식(OCR, Android) — 2026-10-25 추가
- 엔진: Google ML Kit Text Recognition v2, **한국어 모델을 앱에 포함(bundled)** 한 방식. 인식은 기기 안에서 하며, 앱은 이미지·인식된 글자를 어디에도 보내지 않는다. 모델 다운로드가 필요 없다.
- 단, Google의 ML Kit Android 데이터 공개 문서(https://developers.google.com/ml-kit/android-data-disclosure, 2026-10-24 확인)에 따르면 ML Kit는 **진단·사용 분석 목적으로** 기기 정보, 앱 정보, 식별자, 성능 지표, API 설정(이미지 형식·해상도), 입력/출력 크기, 오류 코드 등을 HTTPS로 Google에 보낼 수 있다. 문서에는 이미지 내용이 포함된다는 기재는 없다. 앱에서 이 전송을 끌 공식 옵션은 확인하지 못했다.
- 그래서 설정 > 저장 방식에 **"이미지·PDF 글자 인식" 끄기**를 두고 위 내용을 화면에 고지한다. 끄면 ML Kit를 호출하지 않는다. 현재 기본값은 켜짐 — 기본값은 소유자 결정 사항(DECISIONS D-015).
- 스토어 데이터 보안 신고 시 위 진단 전송을 반영해야 하는지 출시 전 확인 필요(미확인).
- iOS: OCR 미연결(항상 "사용할 수 없음").

## 로그
- `logError`는 오류 범주와 예외 이름만 기록. 원문, URL, 쿠폰/주문 번호, 파일 경로, payload를 남기지 않음(개발 빌드에서만 예외 메시지 추가).

## 내보내기·삭제
- 설정 > 내보내기: "첨부 없이"(데이터만) 또는 "첨부 포함"(이미지·PDF를 base64로 포함, 총 30MB까지). 저장 전에 포함/제외되는 첨부 개수와 이유를 보여 준다. 백업 파일은 **암호화되지 않는다**.
- 가져오기: 형식·크기·해시 검증 후 단일 트랜잭션. 이미 있는 항목은 덮어쓰지 않고 건너뜀. 알림은 꺼진 상태로 복원.
- 모든 데이터 삭제: 경고 후 예약 알림 취소 → DB 비우기 → 앱 폴더(첨부) 삭제. 설정 값과 사용자가 이미 다른 곳에 저장한 백업 파일은 지우지 않는다. 앱 캐시에 남은 내보내기 임시 사본은 OS 캐시 정리에 맡긴다.
- 임시 저장 항목도 일반 항목과 같이 검색·내보내기·삭제 대상이다.

## 향후 백업/동기화를 추가한다면
- 별도 동의 화면, 전송 항목·목적·보관 기간·비용 고지, 종단간 암호화 검토, 계정 삭제 시 서버 데이터 삭제 절차가 선행돼야 한다. 백업을 켜지 않은 사용자의 데이터는 전송하지 않는다.

## 법령·스토어 (출시 전 확인할 것)
- 개인정보보호법 및 개인정보보호위원회(https://www.pipc.go.kr/) 최신 가이드, Apple App Privacy(영양 라벨), Google Play 데이터 보안 섹션. 앱 코드 기준으로는 "수집·전송 없음"이지만, ML Kit(OCR)의 진단 전송을 어떻게 신고할지 출시 시점에 공식 자료로 재확인한다(미확인).
